📚 QuizLive - Guía Completa de Uso

Todo lo que necesitas saber para usar el juego con tus alumnos

📱 ¿Cómo se une un participante al juego?

1 El alumno abre la página web

El alumno debe abrir la misma página web que tú en su celular o computadora. Puede hacerlo de tres formas:

  • Opción A: Escaneando el código QR que generas (ver sección más abajo)
  • Opción B: Escribiendo la URL directamente en el navegador
  • Opción C: Haciendo clic en un enlace que les compartas
2 Selecciona "Unirse como Alumno"

En la pantalla principal, el alumno verá dos botones. Debe presionar el botón 📱 Unirse como Alumno.

3 Ingresa el código de sala

Tú (el profesor) verás un código de 5 caracteres en tu pantalla (ejemplo: A3K7M). El alumno debe escribir ese código exactamente igual en el campo "Código de sala".

💡 Nota: El código distingue entre mayúsculas y minúsculas. Asegúrate de que los alumnos lo escriban correctamente.
4 Escribe su nombre

El alumno escribe su nombre en el campo correspondiente y presiona 🎮 Unirse al Juego.

5 Espera a que inicie el juego

Una vez conectado, el alumno verá una pantalla de espera con su nombre. Cuando tú presiones ▶️ Comenzar Juego, todos los alumnos conectados recibirán la primera pregunta automáticamente.

6 Responde las preguntas

Cada pregunta aparece con 4 opciones de colores diferentes (rojo, azul, amarillo, verde). El alumno tiene 20 segundos para seleccionar una respuesta tocando el botón correspondiente.

  • Mientras más rápido responda correctamente, más puntos gana
  • Solo puede seleccionar una respuesta por pregunta
  • Si no responde a tiempo, no obtiene puntos

💡 Explicaciones de Respuestas Correctas e Incorrectas

¿Qué son las explicaciones?

Las explicaciones son textos que aparecen después de cada pregunta para reforzar el aprendizaje:

  • Explicación correcta: Aparece cuando el alumno acierta. Refuerza por qué esa es la respuesta correcta.
  • Explicación incorrecta: Aparece cuando el alumno falla. Explica cuál era la respuesta correcta y por qué.

¿Cómo agregar explicaciones a tus preguntas?

Para agregar explicaciones, debes crear preguntas personalizadas siguiendo estos pasos:

  1. Ve a la pantalla principal y selecciona 🖥️ Crear Partida (Profesor)
  2. Selecciona la pestaña Crear Preguntas
  3. Haz clic en + Agregar Pregunta
  4. Completa los campos:
    Campo Descripción
    Pregunta El texto de la pregunta que verán los alumnos
    Respuesta A (rojo) Primera opción de respuesta
    Respuesta B (azul) Segunda opción de respuesta
    Respuesta C (amarillo) Tercera opción de respuesta
    Respuesta D (verde) Cuarta opción de respuesta
    Respuesta correcta Selecciona cuál de las 4 es la correcta (A, B, C o D)
    Explicación si acierta Texto que aparece cuando el alumno responde correctamente
    Explicación si falla Texto que aparece cuando el alumno responde incorrectamente

Ejemplo de pregunta con explicaciones:

Pregunta: ¿Cuál es el planeta más grande del sistema solar? Respuesta A (rojo): Júpiter ✅ (CORRECTA) Respuesta B (azul): Saturno Respuesta C (amarillo): Neptuno Respuesta D (verde): Urano Explicación si acierta: "¡Correcto! 🎉 Júpiter es el planeta más grande del sistema solar. Tiene un diámetro de aproximadamente 139,820 km, que es más de 11 veces el diámetro de la Tierra. ¡Es tan grande que cabrían más de 1,300 Tierras dentro!" Explicación si falla: "La respuesta correcta es Júpiter. Aunque Saturno es el segundo planeta más grande, Júpiter lo supera significativamente. Júpiter es un gigante gaseoso compuesto principalmente de hidrógeno y helio."
✅ Beneficios de usar explicaciones:
  • Los alumnos aprenden incluso cuando se equivocan
  • Se refuerzan los conceptos correctos
  • Se proporciona contexto adicional valioso
  • Mejora la retención del conocimiento

🚀 Paso a Paso: Cómo Poner en Funcionamiento el Juego

1 Preparación previa (antes de la clase)
  1. Guarda el archivo HTML en tu computadora con el nombre quizlive.html
  2. Prueba el juego abriendo el archivo en tu navegador (Chrome, Firefox, Edge)
  3. Crea tus preguntas usando la opción "Crear Preguntas" o selecciona un tema prediseñado
  4. Agrega las explicaciones para cada pregunta (correcta e incorrecta)
  5. Genera el código QR (ver sección siguiente) para compartir con los alumnos
2 Durante la clase - Configuración
  1. Abre el archivo quizlive.html en tu navegador
  2. Proyecta tu pantalla para que todos los alumnos vean el código de sala
  3. Presiona 🖥️ Crear Partida (Profesor)
  4. Selecciona un tema prediseñado O crea tus propias preguntas
  5. Presiona 🚀 Iniciar Partida
  6. Anota el código de sala que aparece en pantalla (ej: K7M3P)
3 Durante la clase - Conexión de alumnos
  1. Muestra el código QR o comparte la URL con los alumnos
  2. Diles el código de sala en voz alta y escríbelo en la pizarra
  3. Espera a que los alumnos se conecten (verás sus nombres aparecer en tu pantalla)
  4. Verifica que todos estén conectados antes de comenzar
💡 Consejo: Si algún alumno tiene problemas para conectarse, verifica que:
  • Esté usando el mismo archivo/URL que tú
  • El código de sala esté escrito correctamente
  • Tenga conexión a internet
4 Durante la clase - Jugando
  1. Presiona ▶️ Comenzar Juego cuando todos estén listos
  2. Lee la pregunta en voz alta para todos los alumnos
  3. Espera los 20 segundos mientras los alumnos responden
  4. Revisa los resultados que aparecen automáticamente
  5. Lee las explicaciones para reforzar el aprendizaje
  6. Presiona Siguiente Pregunta → para continuar
  7. Repite hasta completar todas las preguntas
5 Final del juego
  1. Al terminar todas las preguntas, se muestra el podio final
  2. Puedes felicitar a los ganadores
  3. Presiona 🔄 Jugar de Nuevo para otra ronda
  4. O presiona ← Menú Principal para salir
⚠️ Importante sobre la conexión:

Este juego funciona mediante BroadcastChannel API y localStorage, lo que significa que:

  • Funciona mejor cuando todos usan el MISMO navegador en la MISMA computadora (modo demostración)
  • Para uso real con múltiples dispositivos, necesitarías un servidor backend (Node.js, Firebase, etc.)
  • La versión actual es ideal para demostraciones y pruebas
  • Para producción real, considera usar plataformas como Kahoot, Quizizz o implementar un servidor WebSocket

🔧 Solución de Problemas Comunes

Problema: Los alumnos no pueden conectarse

  • Causa: Están usando diferentes navegadores o dispositivos
  • Solución: Esta versión usa BroadcastChannel/localStorage que solo funciona entre pestañas del mismo navegador. Para uso real multi-dispositivo, necesitas un servidor backend.

Problema: El código QR no funciona

  • Causa: La URL en el QR es incorrecta o el archivo no está publicado
  • Solución: Verifica que la URL sea accesible desde cualquier dispositivo. Prábala tú primero desde tu celular.

Problema: Las explicaciones no aparecen

  • Causa: No agregaste las explicaciones al crear la pregunta
  • Solución: Asegúrate de completar ambos campos de explicación (correcta e incorrecta) al crear cada pregunta personalizada.

Problema: El temporizador no funciona correctamente

  • Causa: El navegador puede tener restricciones de rendimiento
  • Solución: Usa Chrome o Firefox actualizado. Evita tener muchas pestañas abiertas.
